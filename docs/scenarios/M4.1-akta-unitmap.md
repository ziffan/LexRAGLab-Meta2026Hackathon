## Skenario

### S1 — Peta unit v2 persis
- Masukan: T + skema v2; `schema_address_map(T, v2)`.
- Jawaban: 5 unit tabel di atas (urut `start`), alamat dan `[start,end)` persis; Rincian Pasal 1 empat buah seperti di atas; unit lain `children = ()`. Tidak ada unit yang memuat indeks 0–8, 31, 51, 127, 148, 165.
- Bug yang ditangkap: spasi tepi tidak dipangkas (`Pasal 1` berakhir 128); Rincian jadi unit; Kepala Akta menelan Komparisi (grup nama diabaikan); `Salinan.` ikut jadi unit.

### S2 — Pipeline akta memakai peta skema aktif (semua setting)
- Masukan: `Pipeline(T, schemas=SchemaBinding(family akta, [v2]))`; setting (a) `structure_schema` v2, (b) `fixed_size` apa pun. `pipe.chunk_set(s)`.
- Jawaban: untuk (a) dan (b): `cs.units == [(9,31),(32,51),(52,127),(128,148),(149,165)]` dan `cs.amap` sama dengan S1. `build_address_map` tidak menjadi sumber `cs.amap` akta. Potongan chunker skema yang persis satu unit beralamat sama dengan unitnya.
- (c) Binding [v1 spark, v2 operator]; setting `structure_schema` dipin `schema_version = 1` (non-aktif): chunk-nya dari v1, tetapi `cs.amap`/`cs.units` tetap peta v2 aktif (P11); potongan v1 `Kepala Akta` [9,51) melintasi dua unit v2 sehingga alamatnya rentang, bukan alamat unit. Pin ke versi yang tidak ada → setting dilewati (S11).
- Bug yang ditangkap: wiring hanya untuk setting `structure_schema` (fixed_size tetap peta lama, Recall@K antar setting tak sebanding); `cs.units` masih `[(0,165)]`; peta mengikuti versi pin tiap setting.

### S3 — UU PT tidak berubah (byte-identik)
- Masukan: dokumen `uupt` mainan (mis. UU-X dari M2.3) dengan `schemas=None`, dan dengan binding skema `uupt`.
- Jawaban: `cs.amap.units` dan `cs.units` identik (alamat, offset) dengan keluaran `build_address_map` langsung; `Pipeline.params(s)` setting non-skema dan `config_hash` grid UU PT sama dengan nilai sebelum perubahan; `unit_map_version` tidak masuk hash UU PT.
- Kontrol (B1): grid UU PT yang hanya berisi setting `fixed_size`, dengan binding skema `uupt` berisi rekaman, ber-`config_hash` sama persis dengan sebelum perubahan, dan amplopnya tanpa blok `unit_map`/`recall_unit`. Sebaliknya grid akta `fixed_size`-saja BERUBAH hash (perilaku baru P2) dan memuat blok `unit_map`.
- Bug yang ditangkap: cabang akta bocor ke `uupt`; kunci cache UU PT bergeser (semua run UU PT tidak valid); `unit_map_version` ditaruh di `retrieval`/`grid` sehingga hash UU PT bergeser.

### S4 — Recall@K dengan unit akta (H-048)
Unit `gold_parts` = `cs.units` S2. Peringkat disuntik; `K = 1`.
- (a) Gold `[100,140)` melintasi Pasal 1 dan Pasal 2. Bagian: `[100,127)` dan `[128,140)` (LF 127 tidak masuk). Top-1 = potongan `[52,127)`: bagian 1 utuh di dalamnya, bagian 2 tidak → `Recall@1 = 1/2`. Top-1 = `[52,148)`: kedua bagian utuh → `2/2`. Peta lama (satu unit [0,165)): satu bagian `[100,140)`; `[52,127)` → `0/1`, `[52,148)` → `1/1`.
- (b) Gold `[127,128)` (LF antar unit) dan gold `[0,8)` (`Salinan.`): 0 bagian → `Recall@K = null` (P7), butir tidak dihitung di rata-rata; peta lama menghasilkan bagian `[0,8)` dan Recall bukan null.
- (c) Gold `[60,100)` (ayat (1) sampai awal huruf a, satu Pasal): satu bagian `[60,100)` (P3). Top-1 = `[52,83)` → `0/1` (alternatif Rincian ayat: bagian `[60,83)`, `[84,100)` → `1/2`; tidak dipilih).
- (d) Gold SEBAGIAN di luar unit `[0,40)`: irisan `[9,31)` dan `[32,40)` = 2 bagian (22 + 8 karakter); `gold_chars_outside_units = 40 - 30 = 10` (`[0,9)` dan `[31,32)`). Top-1 = `[9,31)` → `1/2`. Amplop: `n_items_gold_partly_outside` naik 1; butir (b) menaikkan `n_items_recall_null` (P7).
- (e) Gold melintasi Pasal dan Keterangan Pendiri (unit level default lain) mengikuti mekanisme (a): pecah di batas unit; T tidak punya unit itu, jadi ditutup lewat (a).
- Bug yang ditangkap: gold dipecah memakai peta lama; LF antar unit jadi bagian; Rincian memecah; gold di luar unit menimbulkan pembagian nol atau recall 0 alih-alih `null`; bagian gold di luar unit hilang diam-diam tanpa hitungan.

- Bug yang ditangkap: peta verifier tidak mengikuti `cs.amap` akta; Rincian tak terdaftar; `Batang Tubuh` masih sah; pencocokan awalan (`startswith`).
