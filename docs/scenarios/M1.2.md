## Definisi bersama (dipakai semua skenario)

**Tokenizer mainan `toy-ws` versi `1`.** Token = deretan maksimal karakter bukan-spasi. Untuk teks potongan `D[s:e)`, token diperoleh dari potongan itu saja, dengan offset `[start,end)` mutlak di `D`. Spasi dan newline bukan bagian token. Test nyata memakai tokenizer fake/injeksi dengan perilaku persis ini (bukan tokenizer H-014 asli). `tok(header)` = jumlah kata header dipisah spasi.

**Dokumen mainan T (dipakai S1–S9).** 20 token dua huruf dipisah satu spasi: `a0 a1 a2 a3 a4 a5 a6 a7 a8 a9 b0 b1 b2 b3 b4 b5 b6 b7 b8 b9`. Token ke-i (mulai 0) menempati `[3i, 3i+2)`, spasi di posisi `3i+2`. Panjang T = 59. Contoh: token 3 = `[9,11)`, token 4 = `[12,14)`, token 7 = `[21,23)`, token 9 = `[27,29)`, token 10 = `[30,32)`, token 11 = `[33,35)`.
Potongan yang mencakup token i..j (tanpa spasi tepi): `[3i, 3j+2)`, jumlah token `j-i+1`.

## Asumsi dan pilihan yang perlu disetujui operator

1. **A1 — gabungan span gold sebelum pemecahan. MENYIMPANG dari bunyi harfiah EVAL-SPEC §6**, yang berbunyi "memecah setiap span gold ... menjadi bagian-ayat" dan `parts(q)` = bagian-ayat semua `gold_spans`. Skenario memilih menggabung dulu karena `G` adalah himpunan posisi (§1, §4). **Alternatif harfiah:** pecah tiap span apa adanya (bagian-ayat bisa tumpang tindih/dobel, penyebut Recall@K membesar). Hasil keduanya berbeda hanya bila span bertumpuk (S14 menunjukkan kedua angka). Operator memilih.
2. **A2 (bagian serpihan kata).** Potongan berawal/berakhir di tengah kata menghasilkan token serpihan; serpihan itu gold bila semua karakternya di `G` (S9). Alternatif: token ditentukan dari tokenisasi seluruh dokumen.
3. **A3 (bagian b, c) — truncate bila sisa anggaran setelah header `r ≤ 0`.** Dipilih: potongan itu tidak masuk (tidak pernah potongan header-saja) dan pengemasan berhenti, konsisten dengan `truncate` = tidak ada potongan lagi setelah titik lewat B. Alternatif: potongan itu dilewati seperti `skip`, dan potongan berbiaya kecil sesudahnya masih boleh masuk (S17 menunjukkan kedua angka). Spec diam.
4. **A4 — heading Pasal ber-ayat dan peta alamat (PERTANYAAN).** Peta alamat adalah keluaran parser M1.1 yang belum ada; skenario memakai peta sebagai **masukan test**, bukan klaim tentang parser. Pilihan skenario: heading `### Pasal 1` di luar semua unit ayat, jadi tidak membentuk bagian-ayat (tetap di `G` untuk span recall). Alternatif: heading menjadi bagian-ayat sendiri (penyebut +1); atau unit ayat pertama mencakup heading; atau unit membawa `\n` penutup. S10, S20(a) bergantung; S20(a) menunjukkan angka alternatif.
5. **A5 — Pasal tanpa ayat (PERTANYAAN).** Skenario memetakan unit Pasal tanpa ayat **termasuk heading** (`[52,76)`), padahal pada Pasal ber-ayat heading di luar unit (A4). Asimetri ini sengaja dinyatakan: "Pasal tanpa ayat adalah satu bagian" (§6) ditafsirkan sebagai seluruh Pasal. Alternatif seragam: heading selalu di luar unit (Pasal 2 = `[64,76)`), atau heading selalu bagian sendiri. Operator memilih sekaligus untuk A4 dan A5 agar selaras dengan parser M1.1. S13(b) bergantung.
6. **A6 — `fully_covered` tanpa gold.** Dipilih `null`, keluar dari "x of y" (kontrak bertipe `bool | null`). Alternatif: `true` (∅ = ∅).
7. **A7 — rata-rata presisi atas nilai non-null** (butir bergold dengan `retrieved_tokens=0` keluar dari rata-rata presisi). Alternatif: dihitung 0. **A7b:** bila semua butir null, `mean_token_precision` tak terdefinisi padahal `GridPoint.mean_token_precision` bertipe `number`; dipilih `null` (kontrak perlu dilonggarkan) — alternatif 0.
8. **A8 — `mean_retrieved_tokens`** atas butir bergold saja. Alternatif: semua butir.
9. **A15 — Recall@K saat bagian-ayat kosong.** Gold tidak beririsan dengan unit mana pun (mis. hanya baris kosong) → `parts=∅`. Dipilih `recall_at_k=null` (seperti tanpa gold) sementara span recall tetap dihitung dari `G`. Alternatif: 0, atau seluruh span jadi satu bagian. Kalkulator tidak boleh gagal (S20b).
10. **A16 — Recall@K tanpa gold** `null` (S7); alternatif 0.
11. **A14 — BM25 dan Sastrawi tidak tercakup** di dokumen ini; kalkulator menerima `C` sebagai masukan. Slice M1.2 tidak ditutup tanpa test Tier 2 untuk BM25/Sastrawi dan tabel frontend.
12. **S16 mengikat desain:** pencatatan tokenizer dan packing ke `RunRecord` melampaui kalkulator murni; operator perlu tahu ini bagian slice.

## Skenario

### S1 — Gold terbelah dua potongan, celah uncovered, akumulasi tepat B
- Masukan: T. Potongan khusus S1: `c1=[0,11)` (tok 4) dan `c2'=[12,23)` (token 4–7, tok 4), lalu `c3=[27,32)` (tok 2). `C = (c1, c2', c3)`, `B = 8`, stop, header off. `gold_spans = [[6,20)]` → `G = {6..19}`, `|G| = 14`.
- Langkah hitung: c1 → akumulasi 4 ≤ 8; c2' → 4 + 4 = 8 = B (masuk karena ≤); c3 → 10 > 8 → stop. `P = (c1, c2')`.
  Irisan: c1 `[0,11)∩[6,20) = [6,11)` = 5; c2' `[12,23)∩[6,20) = [12,20)` = 8; posisi 11 (spasi di celah) tidak ditutup siapa pun. `covered = 13`.
  Token gold (semua karakter di G): token 2 `[6,8)`, 3 `[9,11)`, 4 `[12,14)`, 5 `[15,17)`, 6 `[18,20)` = 5; token 7 `[21,23)` bukan. `retrieved = 4 + 4 = 8`.
  Rank: c1 beririsan → 1. Recall@K (K=2): bagian tunggal `[6,20)` tidak seluruhnya dalam c1 maupun c2' → 0.
- Jawaban yang diharapkan: `gold_chars=14`, `covered_gold_chars=13`, `span_recall=13/14` (0.928571); `gold_tokens_retrieved=5`, `retrieved_tokens=8`, `token_precision=5/8` (0.625); `reciprocal_rank=1`; `recall_at_k(K=2)=0`; `fully_covered=false`.
- Bug yang ditangkap: memakai `<` bukan `≤` (c2' ditolak → hasil lain); menghitung celah/spasi antar potongan sebagai tertutup (14/14); menganggap gold "terbelah dua" = tertutup penuh; Recall@K disamakan dengan span recall (1 atau 13/14 bukan 0).

#### S1b — Span gold bertumpuk membentuk G sebagai himpunan
- Masukan: sama S1, tetapi `gold_spans = [[6,12),[10,20)]` (tumpang tindih di 10–11).
- Hitung: `G = {6..19}`, `|G| = 14` (bukan 6 + 10 = 16). Hasil lain identik S1.
- Jawaban: `gold_chars=14`, `span_recall=13/14`, `token_precision=5/8`.
- Bug: menjumlahkan panjang span (penyebut 16 → 13/16) atau pembilang dobel.

### S2 — Potongan tumpang-tindih karena overlap
- Masukan: T. Potongan fixed-size overlap: `A=[0,11)` (token 0–3), `B=[6,17)` (token 2–5), `C=[12,23)` (token 4–7); masing-masing tok=4. `C_rank = (A, B, C)`, `B_budget = 12`, stop. `gold_spans=[[9,14)]` → `G={9..13}`, `|G|=5`.
- Hitung: akumulasi 4, 8, 12 ≤ 12 → `P=(A,B,C)`. Gabungan chars = `[0,23)` ⊇ G → `covered=5`. Token gold unik di covered: token 3 `[9,11)`, token 4 `[12,14)` = 2. `retrieved = 4+4+4 = 12` (duplikasi menambah penyebut). RR = 1 (A beririsan). Recall@K (K=3): bagian `[9,14)` ⊆ B `[6,17)` → 1.
- Jawaban: `span_recall=5/5=1`; `gold_tokens_retrieved=2`, `retrieved_tokens=12`, `token_precision=2/12=1/6` (0.166667); `rr=1`; `recall_at_k=1`; `fully_covered=true`.

#### S2b — Sama, B_budget = 11
- Hitung: A (4), B (8), C membuat 12 > 11 → stop. `P=(A,B)`; union `[0,17)` ⊇ G; `covered=5`; gold token unik 2; `retrieved=8`.

- Bug: potongan melewati B tetap ikut; membandingkan per potongan (bukan akumulasi).

### S3 — Tiga aturan pengemasan pada ranking yang sama
- Masukan: T, `C=(c1,c2,c3,c4)` dengan biaya 4, 5, 2, 3; `B=8`, header off. `gold_spans=[[21,29)]` → `G={21..28}`, `|G|=8` (token 7 `[21,23)`, 8 `[24,26)`, 9 `[27,29)` semuanya gold).
- Hitung:
  - **stop**: c1 → 4; c2 → 9 > 8 → berhenti. `P=(c1)`. covered 0; `retrieved=4`; `gold_tokens=0`; rank tidak ada → RR 0.
  - **skip**: c1 4; c2 dilewati; c3 → 6; c4 → 9 > 8 dilewati. `P=(c1,c3)`. c3 `[27,32)∩G=[27,29)`=2. Token gold di c3: token 9 ya, token 10 `[30,32)` tidak → 1. `retrieved=6`. Rank c3 dalam P = 2 (di C ia peringkat 3).

- Jawaban:

| aturan | P | span_recall | gold_tokens/retrieved | precision | RR |
|---|---|---|---|---|---|
| stop | (c1) | 0/8 = 0 | 0/4 | 0 | 0 |
| skip | (c1,c3) | 2/8 = 1/4 | 1/6 | 0.166667 | 1/2 |
| truncate | (c1,c2') | 2/8 = 1/4 | 1/8 | 0.125 | 1/2 |

- Bug: skip berperilaku seperti stop (atau stop seperti skip); truncate tidak menyesuaikan offset akhir (c2 utuh `[12,26)∩G=[21,26)`=5 → 5/8) atau memasukkan c2 utuh; offset akhir truncate memakai spasi penutup (3/8); RR memakai peringkat di C (1/3 untuk skip) bukan di P; skip berhenti setelah satu lompatan (c4 salah masuk atau c3 tidak masuk).
