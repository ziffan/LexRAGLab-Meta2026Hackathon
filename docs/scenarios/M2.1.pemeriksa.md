## Kesesuaian spec
- Kriteria 1 (transisi hanya dari `usulan`, tanpa jalur ke evaluasi): tercakup kuat (S1–S4, S9, S15, S16). Sesuai `docs/API.md` §5 dan ARCHITECTURE Review store.
- Kriteria 2 (offset ada, teks cocok): S10 mencakup sebagian; celah P1, P2, P8 (di atas).
- Kriteria 3 (tabel difilter per asal, hasil per asal): S19–S22 sesuai EVAL-SPEC §9 (rata-rata per butir, null dikeluarkan, hitungan mentah). Pemecahan per mode dinyatakan di luar scope dan tercatat; wajar.
- Pertentangan dengan spec: S22 vs API §4 `items_summary` (B1).
- API.md W4 menyebut respons "`ProposalRecord[]` + `RunRecord`" (tunggal). S11 menetapkan 2 `RunRecord` (satu per mode) tanpa menandainya sebagai asumsi. Konsisten dengan kunci cache per mode, tetapi perlu dinyatakan sebagai pilihan (C1).
- Tambahan field `clean_sha256` di `ProposalRecord` (A12) mengubah kontrak §9: struktural, jadi menurut AGENTS.md harus lewat log keputusan operator dahulu; skenario sudah menandai "perlu penambahan field".
- `409 hash_mismatch` (A12) dan `422 validation_failed` sudah ada di daftar kode API §1; `500 storage_error` (A15) belum ada dan memang ditandai usulan.
- Label UI S23 dan baris provenance S22 sesuai U6 dan U9 (diperiksa teks per teks).

## Asumsi
- Ditandai wajar sebagai pilihan operator, dan tidak diputus spec: A1–A4 (arti bendera; spec §9 hanya "offset harus cocok"), A6, A7, A9, A12, A13, A15, A16, A17, A19, A20.
- A8 perlu perhatian khusus: API §5 berbunyi "tidak boleh `disetujui` tanpa `edited`", yang paling literal berarti `disetujui` + `edited` valid untuk usulan gagal span adalah sah. Skenario memilih sebaliknya (422) dan ini sudah ditandai; operator wajib memutus eksplisit karena S8/S9(c) menguncinya.
- Dikunci diam-diam (tidak ada di daftar Asumsi): (i) W4 dengan `modes` subset hanya mengembalikan rekaman mode itu (S12 akhir); (ii) W4 mengembalikan rekaman semua status, bukan hanya `usulan`; (iii) `reference_date = null` dan `scene_checked = false` pada `Item` Spark (S5); (iv) urutan hasil filter = urutan masukan (S19); (v) pembuangan A5 hanya "dicatat di log run" tetapi tidak ada asersi pada log itu; (vi) hasil W4 pada keluarga `akta` / `family` tak dikenal tidak ditentukan.
- Tidak ada asumsi penyusun yang sebenarnya sudah diputus spec secara bertentangan. A9 ("butir Spark tanpa gold ditolak") konsisten dengan H-011 dan DATA-CONTRACTS §4 (kontrol wajib-tolak milik operator).
