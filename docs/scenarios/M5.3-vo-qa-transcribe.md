## 3. Masukan

- Direktori VO (`--vo-dir`): berkas `NN-<adegan>.wav` dengan `<adegan>` di `scenes`; berkas lain (`10-alt-S0-B.wav`, `.mp3`) dicetak "skipped". Adegan ganda, atau adegan `scenes` tanpa berkas = galat sebelum panggilan (keluar 2).
- Naskah: kolom "Voice over (Inggris)" tabel "Storyboard terkunci" `docs/VIDEO.md`, satu baris per ID adegan. Bila operator memakai audio alternatif, baris terkunci VIDEO.md diperbarui dulu (alat tidak membaca naskah di luar repo). `--dry-run` mencetak sha256 naskah per adegan dan 6 kata pertamanya.
- Konversi lokal (numpy, sudah dipin): WAV PCM integer 16-bit saja (lain = galat); stereo -> rata-rata kanal; 16/24 kHz apa adanya; kelipatan bulat 24 kHz (48 kHz), selain itu kelipatan bulat 16 kHz (32 kHz) -> FIR low-pass windowed-sinc (Blackman, 129 tap, cutoff 0,45 x laju tujuan) + desimasi; laju lain -> galat. Hasil hanya di memori. Durasi > 600 s atau badan > 32 MB -> galat sebelum panggilan. Versi konversi = `"r1"`.
- Klien HTTP: `urllib.request` stdlib dengan multipart buatan sendiri; tanpa dependensi baru. Opener tanpa proxy env (`ProxyHandler({})`) dan tanpa mengikuti redirect (3xx = galat `http_3xx`, header Authorization tidak pernah dikirim ke host lain); URL wajib `https://`. Transport bisa disuntik (test).

## 4. Biaya, gerbang, cache, store

- Store terpisah `runs/voice_qa/` (tidak dibaca produk): record `runs/voice_qa/spark/records/<run_id>.json` (`store.save_record(runs/voice_qa, ...)`), cache `runs/voice_qa/spark/voice_qa/<key>.json` (`store.cache_write`/`cache_read`/`origin_record`). Pool `meta_voice` = jumlah `spend_micros()` semua record `store.load_records(runs/voice_qa)` (fungsi `pool_spent` alat ini; `Ledger.spent` tidak dipakai karena khusus tampilan): pool terpisah secara fisik, tidak mungkin jatuh ke pool default. Record rusak = galat, keluar 2.
- `runs/voice_qa/` dan `video/qa/vo-report.*` di-commit seperti run lain (repo publik): isinya tanpa key, base URL, host, atau jalur lokal (V11), dan masuk cakupan secret scan gate M5.2 (pemindaian tree penuh).
- Proyeksi per berkas = `ceil(ceil(frames/rate) x audio_per_hour_micros / 3600)` (batas atas; tagihan membulatkan ke bawah).
- Biaya nyata panggilan sukses = `ceil(floor(audioDurationMs/1000) x audio_per_hour_micros / 3600)`.
- Gerbang sebelum panggilan pertama: `belanja pool + proyeksi berkas yang belum di-cache < limit_micros` (ketat; ini juga menjamin proyeksi run < 50.000). Gagal -> keluar 2, 0 panggilan. Berlaku juga di `--dry-run` (vonis dicetak).
- Kunci cache = `sha256(canonical_json(["meta_voice", model, request_json_kanonik, sha256_berkas_audio_asli, "r1"]))`; `request_json` memuat `mode`, `languageBias`, `keywords`. Hit -> 0 panggilan, record asal lewat `origin_record`. Hanya status `ok` yang di-cache.
- Satu upaya per berkas, tanpa retry. Run sah = satu kali setelah izin L1; berkas yang gagal hanya dijalankan ulang atas izin L1 (cache mencegah panggilan ulang berkas `ok`).

## 5. RunRecord (DATA-CONTRACTS §12, store terpisah)

`run_id = uuid4().hex` (`origin_record` mensyaratkan alfanumerik), `kind = "voice_qa"`, `created_at` UTC, `cache_key` §4, `corpus_hash = sha256 berkas audio asli`, `config_hash = config_hash({"voice_qa"})`, `clean_sha256 = null`, `loader_rules_version = null`, `prompt_version = "vo_qa.r1"`, `prompt_hash = null`, `model` dari `config/voice_qa`, `effort = null`, `tokenizer = null`, `embedder = null`, `packing = null`, token `0/0/0` (tidak ditagih per token), `cost_usd_micros` §4, `projected_cost_usd_micros` null kecuali di bawah, `latency_ms` terukur, `host` = label `config/model.host`, `device = "remote"`, `provider = "meta_voice"`, `quantization = null`, `failed_settings = null`.

## 6. Normalisasi teks (sama untuk naskah dan transkrip; WER dan angka dihitung SESUDAH normalisasi)

1. NFKC, huruf kecil, kutip lengkung -> lurus, `&` -> `and`, `%` -> ` percent`, `$X` -> `X dollars`; `every one`/`any one`/`no one`/`some one` -> satu kata (D3 "I review every one" vs transkrip "everyone" bukan beda angka).
2. Angka bertulis: `1,783` -> `1783`; titik desimal hanya bila diapit digit (`1,926.` akhir kalimat = `1926`); `1/10` -> `0.1`; digit+akhiran: `300k` -> `300000`, `5.8x` -> `5.8 x`. Token huruf+digit (`bm25`) tetap utuh; pasangan `bm` + `25` digabung lewat `joined_terms`.
3. Tanda hubung -> spasi; tanda baca (`, ; . : ! ? ( ) "`) dibuang tetapi memutus rangkaian angka.
4. Rangkaian angka (kata dan digit dicampur) -> satu token per bilangan: `three hundred thousand` = `300 thousand` = `300000`; `forty seven thousand` -> `47000`; `one thousand seven hundred eighty three` -> `1783`; `three hundred and two` -> `302`; `a million` = `million` (tanpa pengali) = `1 million` -> `1000000` (`a` numerik hanya sebelum hundred/thousand/million); `one point three` = `1 point 3` -> `1.3` (`point` desimal hanya diapit bilangan/digit kata); `fifty six` -> `56`. Gaya baca berpasangan: satuan/belasan diikuti satuan/belasan/puluhan, atau puluhan diikuti belasan/puluhan = penggabungan string: `eight sixteen` -> `816`, `nineteen twenty six` -> `1926`, `one forty two` -> `142`, `eight one six` -> `816`. Konsekuensi yang dinyatakan: rangkaian tanpa pemisah `eight sixteen seventeen eighty three` -> `8161783` (berbeda dari naskah `816 of 1,783`, jadi `fail`, tidak lulus palsu).
5. `(a|one|1) tenth`, `tenth`, `10th` -> `0.1`; `N cents` (N bulat < 100) -> `0.NN dollars`.
6. Angka kanonik: bulat tanpa nol depan; desimal tanpa nol belakang.

Urutan langkah: (1) teks mentah §6.1-§6.3 (termasuk `1/10` saja, bukan pecahan umum; `10th` dikenali sebelum pemisahan digit+akhiran); (2) rangkaian angka §6.4-§6.5; (3) `joined_terms` terakhir (jadi `BM twenty five` -> `bm 25` -> `bm25`). Penggabungan berpasangan hanya antar KATA angka; dua token digit bersebelahan, atau digit dan kata angka bersebelahan (kecuali kata skala), = bilangan terpisah.

Urutan angka naskah VIDEO.md (dikunci V17): S0 `[1, 300000, 1, 6, 1000000, 0.1]`, S1 `[]`, D1 `[102, 3]`, D2 `[1, 2000, 47000, 8, 6, 5]`, D3 `[14, 2]`, D4 `[69]`, D5 `[]`, T1 `[40, 816, 1783, 1.3, 142, 1926, 3]`, I1 `[0.56]` (dihitung ulang dari kode saat implementasi; beda dari daftar ini = temuan).

## 7. Metrik dan laporan

- Per adegan: WER = jarak Levenshtein kata / jumlah kata naskah (integer basis point untuk ambang, 4 desimal di laporan); daftar beda (sub/del/ins) kata naskah vs transkrip; urutan angka naskah vs transkrip.
- Vonis: `fail` bila urutan token angka tidak identik persis; `review` bila angka cocok dan WER bp > ambang; `pass` selain itu (WER bp == ambang = `pass`). Keluar kode 1 bila ada `fail`, 0 bila tidak.
- Laporan: `video/qa/vo-report.md` + `video/qa/vo-report.json`: model, sha256 audio dan naskah, `run_id`, status cache, biaya per adegan dan total, waktu UTC. Tanpa key, base URL, host, atau jalur absolut (nama berkas saja).
- `--dry-run`: membaca + mengonversi audio, naskah, proyeksi, gerbang; mencetak tabel; tidak memakai atau mencetak nilai key (`.env` di-parse hanya untuk mencetak ada/tidak `MUSE_API_KEY`/`MUSE_BASE_URL`), tidak membuka jaringan, tidak menulis berkas.
