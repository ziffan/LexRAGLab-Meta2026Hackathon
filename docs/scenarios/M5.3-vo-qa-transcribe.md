# Spec M5.3 — pemeriksa voice over dengan Muse Voice Transcribe (H-113)

Status: revisi 1, menunggu pemeriksa L3. Mandat: H-113 (`docs/DECISIONS.md`), `AGENTS.md` pengecualian ketiga. Bukan slice Tier 1; skenario di bawah bukan butir evaluasi (H-006) dan tidak memengaruhi angka hasil. Alat QA video, bukan fitur produk.

## 1. Sumber API (primer, diakses 2026-10-30)

| Hal | Nilai | Sumber |
|---|---|---|
| Model ID | `muse-voice-transcribe-1.0` | https://dev.meta.ai/docs/speech-to-text |
| Endpoint berkas | `POST {MUSE_BASE_URL}/asr/transcribe` (`https://api.meta.ai/v1/asr/transcribe`), `multipart/form-data`, header `Authorization: Bearer` | https://dev.meta.ai/docs/api-reference/voice/transcribe |
| Bagian multipart | `request` (JSON, `application/json`) dan `audio` (`audio/wav`) | idem |
| `request` | `model` (wajib), `audioEncoding` = `WAV` (wajib, satu-satunya nilai), `mode` `PUSH_TO_TALK` (bawaan) / `ENDPOINTING` / `DIARIZATION`, `keywords` (bias kosakata, tidak menjamin ejaan), `languageBias` (nama bahasa, mis. `English`) | https://dev.meta.ai/docs/api-reference/voice/schemas |
| Format audio | RIFF/WAVE, mono, PCM integer 16-bit, 16 kHz atau 24 kHz | idem |
| Batas | badan <= 32 MB (413), audio <= 10 menit (400) | speech-to-text |
| Respons JSON | `{sessionId, transcript, audioDurationMs, turns[]}`; `turns` kosong pada `PUSH_TO_TALK`. Tanpa timestamp per kata dan tanpa skor keyakinan (dinyatakan tidak didukung) | schemas, speech-to-text |
| Harga | $0.18 per jam audio, dihitung per detik utuh dibulatkan ke bawah; permintaan gagal dan 429 tidak ditagih | https://dev.meta.ai/docs/pricing-rate-limits |
| Batas laju | 256 stream serentak, 16.000 stream per jam per tenant; tanpa RPM | idem |

Harga dalam micro-USD: 180.000 per jam = 50 per detik.

## 2. Konfigurasi (nilai dipin sebelum run)

- `config/model`: profil `[profiles.meta_voice]` (provider `meta_voice`, model `muse-voice-transcribe-1.0`, `api = "asr_transcribe"`, `base_url_env = "MUSE_BASE_URL"`, `api_key_env = "MUSE_API_KEY"`, `roles = ["voice_qa"]`, `for_reported_numbers = false`) dan `[pricing.meta_voice] audio_per_hour_micros = 180000`. Key dan base URL sama dengan Contributor (satu key Model API; bukan key kedua).
  - `roles` tidak kosong dan tidak memuat a/b/c: profil tidak muncul di pemilih model U3 dan ditolak W2/W6/CLI pembanding (pola `roles` H-100).
  - `SparkClient` tidak bisa memakai profil ini: blok pricing tanpa `*_per_mtok_micros` -> `config_invalid` di `build_settings` (gagal tertutup, dikunci test).
  - Efek samping yang diterima: `config_hash` aplikasi (hash `config/model` + `config/budget`, tampil di R1) berubah. Kunci cache Spark (ARCHITECTURE §8), kunci grid, dan kunci `measure` tidak memuat hash itu, jadi cache tidak terbuang (dikunci test: kunci cache contoh sama sebelum/sesudah).
- `config/budget`: `[provider_cap_micros] meta_voice = 50000` = batas H-113 (< 50.000 micro-USD). Usulan agen dari H-113, operator boleh ubah.
- `config/voice_qa.toml` (baru, `version = 1`): `mode = "PUSH_TO_TALK"`, `language_bias = ["English"]`, `keywords = []` (bawaan kosong: bias kosakata bisa menutupi salah ucap merek; operator boleh mengisi), `wer_review_threshold_bp = 1000` (WER > 10% = "review"), `timeout_s = 120`, `scene_file_pattern = "^\\d{2}-(S0|S1|D1|D2|D3|D4|D5|T1|I1)\\.wav$"`.

## 3. Masukan

- Direktori VO (`--vo-dir`): berkas `NN-<adegan>.wav` yang cocok pola; berkas lain (`10-alt-S0-B.wav`, `.mp3`) diabaikan dan dicantumkan sebagai "skipped". Adegan ganda atau adegan storyboard tanpa berkas = galat sebelum panggilan.
- Naskah: kolom "Voice over (Inggris)" tabel bagian "Storyboard terkunci" `docs/VIDEO.md`, satu baris per ID adegan. `sha256` naskah per adegan masuk laporan.
- Konversi lokal (numpy, sudah dipin; tanpa dependensi baru, tanpa ffmpeg): WAV PCM 16-bit; stereo -> rata-rata kanal; 16/24 kHz apa adanya; laju kelipatan 24 kHz (mis. 48 kHz) -> FIR low-pass windowed-sinc + desimasi ke 24 kHz; laju lain -> galat. WAV hasil konversi hanya di memori. Durasi > 10 menit atau badan > 32 MB -> galat sebelum panggilan.

## 4. Biaya, gerbang, cache

- Proyeksi per berkas = `ceil(frames / rate)` detik x 50 micro-USD, dibulatkan ke atas (`ceil(detik x audio_per_hour_micros / 3600)`); batas atas karena tagihan membulatkan ke bawah.
- Biaya nyata per panggilan sukses = `floor(audioDurationMs / 1000) x audio_per_hour_micros / 3600`, dibulatkan ke atas ke integer.
- Gerbang sebelum panggilan pertama: `belanja pool meta_voice + proyeksi berkas yang belum di-cache <= plafon pool` DAN `proyeksi < 50.000` (H-113). Gagal -> berhenti tanpa panggilan, keluar kode 2.
- Kunci cache = `sha256(canonical_json(["meta_voice", model, request_json_kanonik, sha256_berkas_audio_asli, versi_konversi]))`. Entri disimpan lewat `store.cache_write(runs, "voice_qa", key, ...)` = `runs/spark/voice_qa/<key>.json`; hit -> tanpa panggilan, RunRecord asal dipakai (`origin_record`), tanpa record baru. Hasil hanya di-cache bila status `ok`.
- Satu upaya per berkas, tanpa retry (H-113 "satu kali run"); berkas gagal bisa dicoba pada run berikut (hanya yang belum di-cache dipanggil).

## 5. RunRecord (DATA-CONTRACTS §12)

`kind = "voice_qa"` (ditambah ke enum; label UI "VO check"), `provider = "meta_voice"`, `model` dari config, `effort = null`, `quantization = null`, token = `0` (tidak ditagih per token), `cost_usd_micros` = biaya nyata §4, `cache_key` §4, `config_hash` = hash `config/model` + `config/budget` + `config/voice_qa`, `prompt_hash` = sha256 naskah adegan, `corpus_hash`/`clean_sha256` = sha256 berkas audio, `device = "remote"`, `host` dari `config/model`. Galat: `status = "error"`, `error = {code, message}` tanpa key/URL; HTTP 4xx/5xx/429 -> `cost = 0` (tidak ditagih per dokumen); timeout/galat koneksi -> `projected_cost_usd_micros` = proyeksi berkas (konservatif, pola H-063). Disimpan `store.save_record` di `runs/spark/records/`.

Pool: `meta_voice` tercantum di `provider_cap_micros`, jadi `Ledger.spent_pool`/`pool_spend` menaruhnya di pool sendiri; pool default (hasil utama, `main_results_spent_usd_micros`) tidak berubah (dikunci test). `ledger_spent_usd_micros` (total semua) ikut naik, sesuai definisinya. UI U8: label pool "VO transcription check (meta_voice pool)".

## 6. Normalisasi teks (dua sisi sama)

1. NFKC, huruf kecil, kutip lengkung -> lurus, `&` -> `and`, `%` -> ` percent`.
2. Angka bertulis: `1,783` -> `1783`; titik desimal dipertahankan; `$X` -> `X dollars`; angka menempel huruf dipisah (`5.8x` -> `5.8 x`).
3. Tanda hubung dan tanda baca -> pemisah; tanda baca (`, ; . : ! ?`) juga memutus rangkaian kata angka.
4. Kata angka -> digit per rangkaian: `three hundred thousand` -> `300000`, `forty seven thousand` -> `47000`, `one thousand seven hundred eighty three` -> `1783`, `three hundred and two` -> `302`, `a million` -> `1000000` (`a` hanya sebelum hundred/thousand/million), `one point three` -> `1.3`, `fifty six` -> `56`. Gaya baca berpasangan digabung: satuan/belasan diikuti satuan/belasan/puluhan, atau puluhan diikuti belasan/puluhan, = penggabungan string: `eight sixteen` -> `816`, `nineteen twenty six` -> `1926`, `one forty two` -> `142`, `eight one six` -> `816`.
5. `N cents` (N bulat < 100) -> `0.NN dollars` (`fifty-six cents` dan `$0.56` setara).
6. Angka kanonik: bulat tanpa nol depan; desimal tanpa nol belakang.

## 7. Metrik dan laporan

- Per adegan: WER = Levenshtein kata / jumlah kata naskah (integer basis point untuk ambang, desimal 4 digit di laporan), daftar beda (sub/del/ins dengan kata naskah vs transkrip), urutan angka naskah vs transkrip.
- Vonis: `numbers_ok` = urutan token angka identik persis; `fail` bila tidak; `review` bila angka cocok tetapi WER > ambang; `pass` selain itu. Keluar kode 1 bila ada `fail`.
- Laporan: `video/qa/vo-report.md` (tabel per adegan + beda) dan `video/qa/vo-report.json` (mesin), memuat model, sha256 audio dan naskah, `run_id`, biaya per adegan dan total, status cache, tanggal UTC. Tanpa key, base URL, atau jalur lokal absolut (jalur VO ditulis relatif nama berkas saja).
- `--dry-run`: membaca dan mengonversi audio, menyelesaikan naskah, menghitung proyeksi dan gerbang, mencetak tabel; tidak membaca key, tidak membuka jaringan, tidak menulis berkas apa pun. Mencetak keberadaan `MUSE_API_KEY`/`MUSE_BASE_URL` (ya/tidak, tanpa nilai) supaya kesiapan terlihat.
