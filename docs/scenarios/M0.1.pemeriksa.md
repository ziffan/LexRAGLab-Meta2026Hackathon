## Kesesuaian spec
- Kriteria selesai MILESTONES M0.1 tercakup. "Cached > 0" dan "catatan run tersimpan" hanya terbukti lewat transport palsu; berkas jujur menyebutnya.
- DATA-CONTRACTS §12: S32 hanya memeriksa sebagian field. `host`, `device`, `tokenizer`, `corpus_hash`, `config_hash`, `clean_sha256`, `loader_rules_version`, `packing`, `embedder` tidak disebut nilainya untuk run Spark. Daftar `provider` §12 hanya `meta` dan `lmstudio_local`; `openrouter` (H-057) belum ada di kontrak, padahal S35 menuntutnya.
- §12 tidak punya field proyeksi, padahal asumsi 10 + S5 menuntut record `cost=null` dihitung sebesar proyeksinya. Dari mana buku belanja memperoleh angka itu saat membaca ulang dari disk?
- Cap: mandat operator (brief L2) = 2.000.000 menang atas env bila env lebih besar; asumsi 12 ("env diabaikan atau dihapus") lebih longgar dari aturan min(cap config, cap env) dan tidak menguji env lebih kecil.
- SPARK-ROLES §1 "timeout satu retry": S18 c/d menguji max_retries 0 dan 2 dari config; tidak bertentangan.
