## Kesesuaian spec
- DATA-CONTRACTS §10 mendefinisikan `QualityMetrics.*: number` (tidak nullable); skenario S1/S10 menuntut `null`. Bentrok kontrak; butuh revisi §10 (`number | null`) atau pilihan lain.
- EVAL-SPEC §7 mendaftar pola entitas: "Pasal n", "ayat (n)", nama peraturan, tanggal, angka bernilai; mainan hanya 3 (diakui di matriks). Pola tanggal/angka bernilai tak teruji.
- EVAL-SPEC §6: `Recall@K(q)` per butir; agregasi lintas butir tidak ditulis, MRR memakai rata-rata atas butir bergold, jadi asumsi 7 (macro) konsisten tetapi tetap penyesuaian yang perlu persetujuan.
- Kriteria selesai M1.5 "definisi ditulis di repo sebelum kode" tidak diuji; matriks sudah mengakui. Panel frontend juga tidak tercakup (bukti visual).
- Kriteria wajib "nomor pasal terbelah" (S3, S8) dan "batas di tengah kalimat" (S3, S3b, S5, S7) tercakup.

## Rekomendasi perbaikan
1. P1: Tambah skenario newline-only: batas b setelah titik + newline yang BUKAN di S (mis. DB varian "saham.\nPasal 4 ...") agar jalur newline di `sent()` tertangkap.
2. P2: Tambah skenario `sent` untuk `dst`, `dll`, dan batas kata (mis. "Ino." harus ok, "No." tidak) dalam satu dokumen mainan.
3. P3: Jalur `b == len(T)` tak terjangkau; hapus dari definisi `sent` atau uji langsung fungsi `sent` (unit) untuk b = len(T).
4. P4: Tambah entitas `Pasal 153A` dan nomor multi-digit, serta satu dokumen mainan dengan karakter non-ASCII (mis. "§"/emoji sebelum entitas) untuk offset code point.
5. P5: Selaraskan DATA-CONTRACTS §10 dengan `null`, atau putuskan nilai penyebut nol; catat sebagai isu "Menunggu operator". Tentukan nilai K=0 di S13 (error atau 0,0).
6. P6: Perbaiki S7 tabel: `T[39]` adalah "k" (bukan "u"). Jelaskan di S16 "tiga kombinasi" (urutan normal/terbalik x header off/on = empat, atau sebut tiganya). Jadikan S16 menguji antarmuka yang menerima teks potongan agar header benar-benar dapat bocor.
7. Catatan: S14 sebut bug "peringkat dari P bukan C" tetapi tidak ada P di masukan; ganti dengan bug positional top-K (yang memang tertangkap). S17 tambah dua panggilan berurutan di satu proses untuk menguji kunci cache. S11 definisikan tiga butir konkret.
